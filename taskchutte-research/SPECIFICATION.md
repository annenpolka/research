# TaskChute 再現実装仕様書

## 1. 概要

TaskChuteは日本発の時間管理・タスク管理手法で、15年以上の歴史を持つ。最新版のTaskChute Cloud 2は2024年8月にリリースされた。

### 1.1 設計思想

- **ボトムアップアプローチ**: 理想を描くトップダウン型ではなく、実際の時間ログから現実的な計画を立てる
- **今この瞬間に集中**: 現在実行中のタスクに集中できる環境を提供
- **先送り0の実現**: タスクを先送りせず、実行可能な計画を作る

### 1.2 開発経緯

- **元祖**: 大橋悦夫氏によるExcel版TaskChute
- **クラウド版**: jMatsuzaki氏が開発したTaskChute Cloud
- **最新版**: TaskChute Cloud 2（2023年8月〜2024年8月開発）

## 2. コアコンセプト：3つの柱

### 2.1 Plan（計画）

**目的**: 実現可能なタスクリストの作成

**機能要件**:
- タスクの順序付き登録（今日やるタスクを時系列順に並べる）
- 各タスクに見積時間を設定
- 開始予定時刻の自動計算
- タスクの完了予定時刻の表示
- 残り時間のリアルタイム表示

**重要な設計原則**:
- すべてのタスクを登録する必要はない（重要なタスクのみでOK）
- 見積時間は概算値でよい
- 過去のログから平均実行時間を自動計算して見積もりに反映可能

### 2.2 Log（記録）

**目的**: タスク実行の詳細な記録

**機能要件**:
- 開始時刻の記録（手動入力またはボタンクリック）
- 終了時刻の記録
- 実際にかかった時間の自動計算
- 見積時間との差分計算（超過/短縮）
- タスクごとのノート・メモ記録
- 写真やファイル添付
- Markdown対応のノート機能

**データ項目**:
- タスク名
- 開始時刻
- 終了時刻
- 実行時間
- 見積時間
- 差分時間（オーバータイム）
- ノート内容
- 添付ファイル

**エクスポート機能**:
- CSV形式でのログエクスポート
- 期間指定（最大1ヶ月単位）
- 日付指定でのダウンロード
- 外部サービスへの連携（Evernote、Googleカレンダーなど）

### 2.3 Routine（ルーチン）

**目的**: 繰り返しタスクの自動化と習慣化

**機能要件**:
- ルーチンタスクの登録
- 繰り返しパターンの設定
  - 毎日
  - 毎週（曜日指定）
  - 毎月（日付指定）
- 開始予定時刻順での自動生成
- ルーチンからの個別タスク生成
- 柔軟な調整（スキップ、時間変更など）

**特徴**:
- 前日のタスクを振り返り、繰り返すべきものをルーチン化
- ルーチンは固定的ではなく、状況に応じて調整可能
- 自動生成されるため、毎日登録する手間が不要

## 3. データ構造

### 3.1 タスク（Task）

```
Task {
  id: string
  name: string                    // タスク名
  estimatedMinutes: number        // 見積時間（分）
  startTime: datetime?            // 開始時刻
  endTime: datetime?              // 終了時刻
  actualMinutes: number?          // 実際の実行時間
  overtimeMinutes: number?        // 超過時間（負の値の場合は短縮）
  status: enum                    // 'pending', 'in_progress', 'completed', 'skipped'
  scheduledStartTime: datetime?   // 予定開始時刻
  scheduledEndTime: datetime?     // 予定終了時刻

  // 分類
  project: Project?               // プロジェクト
  mode: Mode?                     // モード
  tags: Tag[]                     // タグ
  section: Section?               // セクション

  // 追加情報
  note: string?                   // ノート（Markdown）
  attachments: Attachment[]       // 添付ファイル
  checklist: ChecklistItem[]      // チェックリスト

  // ルーチン関連
  routineId: string?              // 元になったルーチンのID

  // メタデータ
  createdAt: datetime
  updatedAt: datetime
  completedAt: datetime?
}
```

### 3.2 ルーチン（Routine）

```
Routine {
  id: string
  name: string                    // ルーチン名
  estimatedMinutes: number        // 見積時間（分）

  // 繰り返し設定
  repeatType: enum                // 'daily', 'weekly', 'monthly'
  repeatInterval: number          // 繰り返し間隔
  repeatDaysOfWeek: number[]?     // 曜日指定（0-6、日曜=0）
  repeatDayOfMonth: number?       // 月の日付指定（1-31）

  // 時刻設定
  scheduledTime: time?            // 予定時刻

  // 分類
  project: Project?
  mode: Mode?
  tags: Tag[]
  section: Section?

  // テンプレート
  noteTemplate: string?           // ノートテンプレート
  checklist: ChecklistItem[]      // チェックリストテンプレート

  // メタデータ
  isActive: boolean               // 有効/無効
  createdAt: datetime
  updatedAt: datetime
}
```

### 3.3 プロジェクト（Project）

```
Project {
  id: string
  name: string                    // プロジェクト名
  summary: string?                // 概要
  memo: string?                   // メモ
  color: string?                  // 表示色
  order: number                   // 並び順
  createdAt: datetime
  updatedAt: datetime
}
```

**用途**: タスクの大きな分類（例：「ブログ」「仕事」「個人」）

### 3.4 モード（Mode）

```
Mode {
  id: string
  name: string                    // モード名
  summary: string?                // 概要
  memo: string?                   // メモ
  color: string?                  // 表示色
  order: number                   // 並び順
  createdAt: datetime
  updatedAt: datetime
}
```

**用途**: 作業の性質・活動の種類（例：「作成」「レビュー」「会議」「学習」）

### 3.5 タグ（Tag）

```
Tag {
  id: string
  name: string                    // タグ名
  summary: string?                // 概要
  memo: string?                   // メモ
  color: string?                  // 表示色
  order: number                   // 並び順
  createdAt: datetime
  updatedAt: datetime
}
```

**用途**: より具体的なトピックやカテゴリー（例：「TaskChute Cloud2」「Python」「緊急」）

### 3.6 セクション（Section）

```
Section {
  id: string
  name: string                    // セクション名
  order: number                   // 並び順
  createdAt: datetime
  updatedAt: datetime
}
```

**用途**: 1日の時間帯を区切る（例：「午前」「午後」「夜」）

### 3.7 チェックリスト項目（ChecklistItem）

```
ChecklistItem {
  id: string
  text: string                    // 項目テキスト
  isCompleted: boolean            // 完了フラグ
  order: number                   // 並び順
  urlScheme: string?              // 他アプリ起動用URLスキーム
}
```

### 3.8 添付ファイル（Attachment）

```
Attachment {
  id: string
  fileName: string
  fileType: string                // MIME type
  fileSize: number
  url: string                     // ファイルのURL
  uploadedAt: datetime
}
```

## 4. 主要機能

### 4.1 タスク管理機能

#### 4.1.1 タスク作成・編集

- タスク名の入力
- 見積時間の設定
- プロジェクト、モード、タグの選択
- セクションへの割り当て
- ノートの記入（Markdown対応）
- チェックリストの追加
- 添付ファイルの追加

#### 4.1.2 タスク実行

- 開始ボタンクリックで開始時刻を記録
- または手動で開始時刻を入力
- 終了ボタンクリックで終了時刻を記録
- 実行時間の自動計算
- 超過時間の表示（見積時間を超えた場合）
- 次のタスクへの自動移動

#### 4.1.3 タスク一覧表示

- 今日のタスクリストを時系列順に表示
- 現在実行中のタスクをハイライト
- 残り時間のリアルタイム表示
- 見積終了時刻の表示
- フィルタリング機能（プロジェクト、モード、タグ、セクション）
- ソート機能
- ドラッグ&ドロップでの順序変更

#### 4.1.4 時間表示機能

**現在時刻の表示**: リアルタイムで更新

**残り時間の表示**:
- 現在のタスクの残り時間
- 見積時間 - 経過時間
- マイナスになった場合は超過時間として表示

**予定終了時刻の計算**:
- 現在時刻 + 残りのタスクの見積時間合計
- タスクを追加・削除・変更すると自動で再計算

**タイムライン表示**:
- 時間軸上にタスクを配置
- 視覚的な時間管理

### 4.2 ルーチン管理機能

#### 4.2.1 ルーチン作成

- ルーチン名の設定
- 繰り返しパターンの選択
- 開始予定時刻の設定
- テンプレートとしてのノート・チェックリスト設定

#### 4.2.2 ルーチンからのタスク生成

- 毎日自動的に該当日のタスクを生成
- 生成されたタスクは個別に編集可能
- ルーチンを変更しても過去生成済みのタスクは影響を受けない

#### 4.2.3 ルーチン一覧管理

- ルーチンの一覧表示
- 有効/無効の切り替え
- CSVエクスポート

### 4.3 ログ・振り返り機能

#### 4.3.1 日次レビュー

- その日実行したタスクの一覧
- 実行時間の合計
- 見積時間との差分
- ノートの振り返り

#### 4.3.2 カレンダー表示

- 過去のタスク実行履歴をカレンダー形式で表示
- 期間を指定して俯瞰
- 日付クリックでその日のタスク詳細へ

#### 4.3.3 統計・分析

- プロジェクト別の時間集計
- モード別の時間集計
- タグ別の時間集計
- タスク別の平均実行時間
- 見積精度の分析

#### 4.3.4 エクスポート

- CSV形式でのログエクスポート
- 日付指定、期間指定（最大1ヶ月）
- プロジェクト、モード、タグでのフィルタリング

### 4.4 ビュー管理機能

#### 4.4.1 カスタムビュー

- 表示項目のカスタマイズ
- フィルター設定の保存
- ソート順の保存
- デスクトップ用とモバイル用で別設定可能

#### 4.4.2 複数ビューの作成

- 用途別にビューを作成
- ビューの切り替え
- デフォルトビューの設定

### 4.5 キーボードショートカット

- タスク開始/終了: 特定のキー
- 次のタスクへ移動
- 前のタスクへ移動
- タスク追加
- ショートカット一覧表示: Shift + ?

## 7. ユーザーフロー

### 7.1 典型的な1日の流れ

#### 朝（Plan）
1. TaskChute Cloudを開く
2. 今日やるタスクをリストアップ
3. 各タスクに見積時間を設定
4. ルーチンから自動生成されたタスクを確認
5. 必要に応じてタスクの順序を調整
6. 1日の予定終了時刻を確認

#### 日中（Do + Log）
1. 最初のタスクの開始ボタンをクリック
2. タスクに集中して作業
3. 完了したら終了ボタンをクリック
4. 次のタスクへ自動的に移動
5. 必要に応じてノートにメモを追記
6. 予定と実際の時間を比較しながら調整

#### 夜（Check & Action）
1. 今日実行したタスクを振り返り
2. 繰り返すべきタスクをルーチンに登録
3. 明日のタスクを準備
4. 実行時間のログを確認

### 7.2 ルーチン活用フロー

1. 毎日行うタスクを特定
2. ルーチンとして登録
3. 繰り返しパターンと時刻を設定
4. 翌日以降、自動的にタスクが生成される
5. 生成されたタスクを必要に応じて調整
6. ルーチン自体も柔軟に変更

## 13. まとめ

TaskChuteは単なるTodoリストではなく、**時間を軸としたタスク管理システム**です。重要な特徴は：

1. **時系列順のタスク配置**: タスクを順番に並べる
2. **見積と実績の記録**: 時間を意識した計画と実行
3. **ルーチン化**: 繰り返しタスクの自動化
4. **ログからの学習**: 過去のデータから改善

再現実装する際は、この「時間管理」という核心的なコンセプトを中心に据え、シンプルで使いやすいUIを提供することが重要です。
