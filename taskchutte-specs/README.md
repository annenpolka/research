# TaskChute 再現実装仕様

## 概要

TaskChute（タスクシュート）は、日本発のタスク管理・時間管理メソッドおよびそれを実装したツール群です。このドキュメントでは、TaskChuteの再現実装に必要な仕様を調査結果に基づいてまとめています。

## TaskChuteとは

### メソッドとしてのTaskChute

TaskChuteは、シゴタノ！の大橋悦夫氏が考案したタスク管理メソッドで、**タスクシュート時間術**とも呼ばれます。15年以上の歴史を持つ日本独自の時間管理手法です。

**主な特徴：**

1. **1日分の仕事を1シートで管理** - 本日のタスクを一元化
2. **二重リスト管理** - "これからやる仕事"と"やった仕事"を同時管理
3. **時間管理の徹底** - 1分以上かかる全ての仕事を記録
4. **見積もり時間の設定** - 各タスクの所要時間を事前に算出
5. **終了時刻の自動予測** - すべてのタスク完了時刻をリアルタイムで把握

### ツールとしてのTaskChute

メソッドを具体的に実践するためのデジタルプラットフォームとして、以下の公式ツールが存在します：

- **TaskChute2** - Excel版（最も古いバージョン）
- **Taskuma（たすくま）** - iOSアプリ版
- **TaskChute Cloud** - Web版（2025年1月19日にサービス終了）
- **TaskChute Cloud 2** - 最新のクラウド版（2024年8月リリース）

## 基本アーキテクチャ

### 3つの軸：Plan・Log・Routine

TaskChuteは以下の3要素を中心に設計されています：

#### 1. プラン（Plan）
- 日々のタスク計画を立案
- その日一日にやることを順番通りに並べる
- 各タスクに見積もり時間を設定
- ボトムアップ志向で現実に即したタスク実行に重点

#### 2. ログ（Log）
- 開始・終了時刻を記録
- 実績データを蓄積
- タスクごとに詳細な記録を残す
- 過去の実績から次回の見積もりを改善する循環

#### 3. ルーチン（Routine）
- デイリー、週1、月1など定期的なタスクを自動化
- テンプレート的な役割
- サイクル設定に基づいて自動的にタスクリストに表示

## データモデル

### タスク（Task）

タスクは以下の属性を持ちます：

**必須属性：**
- **タスク名** - タスクの名称
- **見積もり時間** - タスクの所要時間予測（分単位）
- **実績時間** - 実際の実行時間（開始・終了時刻から計算）

**オプション属性：**
- **開始時刻** - タスク開始時刻
- **終了時刻** - タスク終了時刻
- **プロジェクト** - タスクが属するプロジェクト
- **モード** - タスクの実行モード（作業の種類など）
- **タグ** - タスクに付与するタグ（複数可）
- **セクション** - タスクが属する時間区間
- **ノート** - 手順、メモ、議事録などの詳細記録（マークダウン対応）
- **色** - タスクの表示色

**派生情報：**
- **超過時間** - 見積もり時間を超えた場合の超過分
- **終了予定時刻** - 残りタスクの見積もりから計算される完了予測時刻

### プロジェクト（Project）

- タスクを分類するための属性
- 各プロジェクトにノートを保存可能
- 色の設定が可能

### モード（Mode）

- タスクの実行モードを表す属性
- 作業の種類や状態を分類
- 各モードにノートを保存可能
- 色の設定が可能

### タグ（Tag）

- TaskChute Cloud 2で追加された機能
- タスクに複数付与可能
- 各タグにノートを保存可能
- 色の設定が可能

### セクション（Section）

**概念：**
- 任意で設定した「時間の区間」
- 1日を複数の時間帯に分割する機能
- 例：9:00～10:30、16:30～18:00

**テンプレート機能：**
- 複数のセクションテンプレートを作成可能（Cloud 2の特徴）
- 平日用と土日用など、異なるテンプレートを使い分け

**テンプレート設定：**
- **サイクル設定** - 毎日、平日、土日、特定の曜日など
- **優先度設定** - 複数テンプレート重複時の適用順序（数字が大きいほど優先）

**使用例：**
- 月末の最終日が平日の場合、"月末締め処理"テンプレート（優先度高）が"平日用"テンプレート（優先度低）より優先される

### ルーチンタスク（Routine Task）

**概念：**
- 繰り返し実行するタスクのテンプレート
- 設定した周期に基づいて自動的にタスクリストに生成される

**設定可能な繰り返し頻度：**
- 毎日
- 平日（月～金、祝日除外）
- 土日
- 特定の曜日
- カスタム間隔（毎週、隔週など）
- 週次、月次

**状態管理：**
- **アクティブ** - 有効化されており、自動生成される
- **非アクティブ** - 無効化されており、自動生成されない

**制限：**
- 無料プランで最大20個のルーチン登録可能

## 主要機能

### 1. タスク実行管理

**タイマー機能：**
- タスク実行中にタイマー表示
- 見積もり時間との比較表示
- 超過時の超過時間カウントアップ
- 例：15分見積もりで15分超過すると超過時間を表示

**開始・終了操作：**
- タスクの開始ボタン押下で開始時刻記録
- 終了ボタン押下で終了時刻記録
- 実績時間の自動計算

**終了予定時刻の自動計算：**
- 残りタスクの見積もり時間から完了予定時刻を算出
- リアルタイム更新

### 2. ノート機能

**マークダウン対応：**
- 各タスク、ルーチン、プロジェクト、モード、タグにノートを保存可能
- 手順、メモ、議事録を記録
- 画像の貼り付けにも対応

### 3. カレンダー表示

**期間俯瞰：**
- タスク画面を期間指定で表示
- 日単位、週単位での表示切り替え
- 無料プラン：7日間表示
- プロプラン：無制限表示

### 4. カスタマイズ機能

**表示設定：**
- フィルター設定
- 並び替え設定
- 表示項目のカスタマイズ
- PCとスマホで異なる表示設定が可能

**色設定：**
- タスク、ルーチン、プロジェクト、モード、タグの単位で色を設定可能

### 5. 見積もり時間の学習

**自動見積もり：**
- 過去のタスク実行ログから平均値を計算
- 次回の見積もり時間として自動設定
- より正確で迅速な見積もりを実現

### 6. キーボードショートカット

- 効率的なタスク操作に対応
- 詳細な仕様は要調査

## ユーザーインターフェース

### レイアウト

**左サイドバー：**
- セクション管理
- プロジェクト管理
- モード管理
- タグ管理
- ルーチン管理

**メイン画面：**
- タスクリスト（順番に並んだタスク）
- タイマー表示
- 終了予定時刻表示

**タスクアクション：**
- タスク追加
- タスク編集
- タスク削除
- 開始/終了ボタン
- ノート表示/編集

### 操作フロー

**基本的な1日の流れ：**

1. **朝：プランニング**
   - セクションテンプレートが自動適用される
   - ルーチンタスクが自動生成される
   - 追加のタスクを手動で追加
   - 各タスクの見積もり時間を設定（過去ログから自動提案）
   - タスクの順序を調整

2. **日中：実行**
   - 最初のタスクの開始ボタンを押下
   - タイマーが動作開始
   - 終了予定時刻がリアルタイム更新
   - タスク完了時に終了ボタン押下
   - 必要に応じてノートにメモを記録
   - 次のタスクへ移行

3. **夜：レビュー**
   - 実績時間と見積もり時間を比較
   - 大きく乖離したタスクを分析
   - 次回の見積もり精度向上に活用
   - カレンダー表示で1週間の振り返り

## プラン別機能制限

### 無料プラン

- 基本的なタスクシュート実践に対応
- **タスク数制限：** 1日40タスクまで
- **タスク表示期間：** 7日間
- **ルーチンタスク：** 最大20個
- **カレンダー表示：** 日・週単位

### プロプラン

- **タスク数：** 無制限
- **タスク表示期間：** 無制限
- **分析期間：** 無制限
- **カレンダー表示：** 無制限

## 技術的考慮事項

### データ永続化

**必要なデータストレージ：**
- タスクの履歴データ（ログ）
- ルーチンタスクの定義
- プロジェクト、モード、タグのマスタデータ
- セクションテンプレート
- ノートデータ

### リアルタイム計算

**動的に計算が必要な項目：**
- 現在実行中タスクの経過時間
- 見積もり時間との差分
- 終了予定時刻
- 1日の総見積もり時間
- 1日の総実績時間

### データ分析機能

**過去ログからの算出：**
- タスク別平均実行時間
- プロジェクト別時間集計
- モード別時間集計
- 日別、週別、月別の集計

## 補足：TaskChuteの哲学

### "先送り0"の実現

TaskChuteの最大の特徴は「先送り0を実現する」という点です。これは以下のアプローチによって達成されます：

1. **現実的な計画** - 自分の能力に合ったタスクリストを作成
2. **見積もりの改善** - 実績データから継続的に見積もり精度を向上
3. **ボトムアップ志向** - トップダウン的な理想論ではなく、現実に即した実行

### 時間管理の統合

TaskChuteは「時間管理とタスク管理とスケジュール管理は同時にやらないと意味がない」という思想に基づいています。これにより：

- タスクを単なるToDoリストではなく時間軸で管理
- 実行可能性の高い計画を立案
- 現実的な終了予定時刻を把握

## まとめ

TaskChuteは15年以上の歴史を持つ日本発の時間管理メソッドであり、その実装には以下の要素が重要です：

1. **タスクと時間の統合管理** - 見積もり時間と実績時間の両方を管理
2. **リアルタイム計算** - 終了予定時刻の自動更新
3. **ログベースの改善** - 過去の実績から見積もり精度を向上
4. **ルーチンの自動化** - 繰り返しタスクの自動生成
5. **柔軟な分類** - プロジェクト、モード、タグ、セクション
6. **詳細な記録** - マークダウン対応のノート機能

これらの機能を段階的に実装することで、TaskChuteの再現が可能になります。
