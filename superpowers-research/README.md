# Superpowers 調査レポート

## 概要

**Superpowers**は、AIコーディングエージェント（Claude Code、Codex、OpenCode）向けの包括的なスキルライブラリとワークフローシステムです。ソフトウェア開発のベストプラクティスを「スキル」として構造化し、エージェントがコードを書く前、書いている間、書いた後に適用できるようにしています。

- **作者**: Jesse Vincent (obra)
- **バージョン**: v4.1.1 (2026-01-23時点)
- **対応プラットフォーム**: Claude Code, Codex, OpenCode

## 設計哲学

Superpowersは以下の原則を厳格に適用します：

1. **TDD（テスト駆動開発）は必須** - オプションではない
2. **修正前の体系的デバッグ** - 根本原因の調査が先
3. **設計ファーストの開発** - ブレインストーミングを通じた設計
4. **サブエージェント駆動の実装** - 2段階レビュー付き
5. **完了宣言前の検証** - 証拠なしに完了を主張しない

## コアアーキテクチャ

### 1. スキル発見システム

**エンジン**: `/lib/skills-core.js` (~210行)

```javascript
// 主要な機能
extractFrontmatter(filePath)     // SKILL.mdからYAMLメタデータを抽出
findSkillsInDir(dir, sourceType) // ディレクトリ内のスキルを再帰検索
resolveSkillPath(skillName)      // スキル名をパスに解決（シャドウイング対応）
```

**スキルのシャドウイング優先順位**:
1. 個人スキル (`~/.claude/skills/`)
2. Superpowersスキル (`/skills/`)
3. 明示的プレフィックス: `superpowers:skill-name` で強制

### 2. スキル構造

各スキルは以下の形式のMarkdownファイル（SKILL.md）として定義：

```markdown
---
name: skill-name
description: "Use when [条件] - [何をするか]"
---

# スキルの内容
```

### 3. プラットフォーム統合

| プラットフォーム | 統合方法 | 特徴 |
|-----------------|---------|------|
| **Claude Code** | 組み込みプラグインシステム | `/superpowers:brainstorm` 等のコマンド |
| **OpenCode** | `system.transform` フック | システムプロンプト注入 |
| **Codex** | `~/.codex/AGENTS.md` 経由 | カスタムコマンド |

## ワークフロー

### 基本ループ

```
1. セッション開始
   ↓
2. session-start.sh がフック実行
   ↓
3. エージェントが using-superpowers スキルを受け取る
   ↓
4. 「適用すべきスキルがあるか？」をチェック
   ↓
5. 該当スキルを呼び出して従う
   ↓
6. 次のタスクへ（ループ）
```

### サブエージェント駆動開発フロー

```
タスクごとに:
├─ 実装サブエージェントを派遣
│  ├─ 明確化のための質問
│  ├─ TDDで実装
│  ├─ セルフレビュー
│  └─ コミット
├─ 仕様レビュアーサブエージェントを派遣
│  └─ 「実装は仕様に合致しているか？」
├─ コード品質レビュアーサブエージェントを派遣
│  └─ 「コード品質、パターン、テストは適切か？」
└─ タスク完了としてマーク

全タスク完了後:
└─ 最終コードレビュアーを派遣
   └─ 実装全体をレビュー
```

## 鉄則（Iron Laws）

### 1. スキル必須実行
> 「スキルが適用される可能性が1%でもあれば、**絶対に**そのスキルを呼び出さなければならない」

**危険な兆候**:
- 「それが何か分かっています」
- 「これは単純です」
- 「まず探索させてください」

### 2. 証拠なしに完了を宣言しない
> 「**現在のセッション**で検証コマンドを実行しなければならない。以前の結果に基づいて成功を主張してはいけない」

### 3. TDDの鉄則
> 「**失敗するテストなしに本番コードを書いてはいけない**」

手順: テストを書く → 失敗を確認 → 最小限のコードを書く → 成功を確認

### 4. 修正前に根本原因
> 「**根本原因の調査なしに修正してはいけない**」

4フェーズ: エラーを読む → 再現する → 変更を確認 → 証拠を収集

## 主な特徴

### 1. クロスプラットフォームサポート
- Claude Code（ネイティブプラグイン）
- Codex（手動セットアップ）
- OpenCode（シンボリックリンク + ネイティブスキル）
- Windows対応（CRLF処理、フック実行）

### 2. タスクごとの新鮮なコンテキスト
- 各タスクに**新しい**エージェントインスタンス
- 前のタスクからのコンテキスト汚染なし
- 完全なタスクテキストを注入（ファイル参照ではない）

### 3. 2段階レビュー
- **ステージ1**: 仕様準拠 - 「要件に合致しているか？」
- **ステージ2**: コード品質 - 「コードは良いか？」

### 4. スマートGit Worktree管理
- 自動ディレクトリ検出
- CLAUDE.md設定の読み取り
- 安全性検証

## 結論

Superpowersは、AIコーディングエージェントに規律あるソフトウェア開発プラクティスを強制するための、よく設計されたシステムです。

**強み**:
- 厳格なTDD/デバッグ/検証の強制
- サブエージェント分離によるコンテキスト管理
- 複数プラットフォーム対応
- カスタマイズ可能（個人スキルでオーバーライド）

**ユースケース**:
- AIエージェントを使った品質重視の開発
- チーム全体で一貫した開発プラクティスの適用
- 複雑なタスクの体系的な分解と実行

**学べるポイント**:
- スキルベースのプロンプト設計パターン
- サブエージェント駆動の並列実行アーキテクチャ
- クロスプラットフォームAIツール統合の実装方法
